# Claude 额度动态

本目录仅保留 Claude 配置、识别提示词、时间策略和共享引擎的薄入口。

- 主信源是 `site/reset-monitors.ts` 的非空多账号名单，初始为 `@ClaudeDevs`；未配置作者仅作上下文，不能成为官方承诺。
- 识别与其他重置监控共用 `MONITOR_MODEL` 和后台 `monitor` 模型选择，未指定时使用 `LLM_*` 默认模型，不提供独立选择。
- 启用额度重置、重置卡及 `bonus_credit` 奖励额度事件。官方一次性云会话赠额属于奖励额度；额度提升、API 赠金、普通限额调整及日常自动重置规则不生成事件。独立消费池与可兑换的重置次数必须区分，不能因为出现 claim/credit 或领取截止时间就视为重置卡。
- 奖励额度的资格条件、领取方式、领取截止及到期分别保留；缺金额、时间或时区不补齐。可领取仅表示官方活动开放，不表示个人到账。页面名称使用“Claude 额度动态”，保留现有 URL、模块及任务标识。
- Claude 专属非重置命题校验放在本模块，通过共享定义的 `excludeProposition` 接入；保留原始模型结果与排除原因，不覆盖人工决定。混合消息逐命题处理，不能因同帖出现赠额就丢弃真实重置。
- 明确套餐、产品和五小时／周范围忠实保留；未说明不得补齐。
- 一次性云会话奖励的后续细则允许通过已核验的官方线程指代同一活动；新增活动仍要求明确一次性云会话奖励证据。消费方式与领取方式、订阅资格与 GitHub 使用前提分别保留。
- 时间只按原帖明确时间换算；缺时区或时间时保留原话，不套用 Tibo 惯例、不让模型预测。
- 通用实现和新增迁移放在 `../reset-monitor/`，不复制后端或页面实现，不另建数据表。
- 测试仅使用独立测试数据库与本地假服务；不自动开启真实采集或推送。

- 统一执行共享引擎的非回复主帖增量流程；不采回复、自回复、转推，不补采父帖，不使用旧初始化、历史查漏或处理模式。主帖识别后关联事件并补齐 v2；历史事件及相关证据保留，无关旧采集数据按可预览、可恢复的清理计划删除。
