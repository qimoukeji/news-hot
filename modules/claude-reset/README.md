# Claude 额度动态

跟踪配置账号的 Claude 额度重置、重置卡和一次性奖励额度，以动作时间线展示当前状态、适用范围和原帖链接。初始账号为 [@ClaudeDevs](https://x.com/ClaudeDevs)，账号、产品和套餐在 `site/reset-monitors.ts`。页面、模块和任务标识保留，通用实现使用[共享重置监控引擎](../reset-monitor/README.md)。

## 运行与识别

使用 `CLAUDE_RESET_PROVIDER`、`CLAUDE_RESET_SCAN_MINUTES` 和共享 `MONITOR_MODEL`；默认 SocialData、每 15 分钟扫描，也支持 TwitterAPI.io。`site/reset-monitors.ts` 中的 collection 分别以 includeReplies 控制回复他人、includeSelfReplies 控制自回复、resetOnly 控制关键词加模型过滤；本站 includeSelfReplies=true，includeReplies 与 resetOnly 为 false；主帖始终开启，纯转推排除。两个回复开关均关闭时只采主帖，分别开启时加采对应类别，都开启时加采全部回复。第三方查询负责回复类别筛选，本地不重复按回复目标账号过滤，缺失账号不丢弃帖子。引用对象及其父帖关系保存为可复用材料，上下文先读取本轮响应和当前监控已存帖子，仍缺失时按明确 ID 付费补采；外部作者和窗口外材料只作上下文，不自动生成官方事实。配置修改后重启 API 与 worker，完整规则见[共享引擎](../reset-monitor/README.md#采集与运行)。

官方一次性云会话赠额归入奖励额度，独立消费池不等于重置使用计数；重置卡必须明确可兑换重置次数。API 赠金、每月 API credits、额度提升、普通限额调整与日常自动重置不生成事件。混合帖子逐项判断，跨账号关联须有同一活动依据，范围冲突转人工复核。

动作分为预告、确认、进展、修订；取消通过修订的 invalidatesEvent=true 表达，同一事实多帖只补来源，同帖可支持多个动作。新事件可直接确认，所有状态和时间都从有效动作推导。奖励可领取表示活动开放，不代表个人到账；领取截止、奖励到期与生效时间分别表达，不计入重置次数。活动关闭、到期和重开须有明确动作依据。

三类事件有效确认均为 completed；关闭领取、到期、重开使用 progress，取消使用带 invalidatesEvent=true 的 amend，取消为业务终态，只能更正或删除错误取消动作后重算。普通 amend 不覆盖有效官方确认。动作的来源引用只保存 postId，sequence 维护事件内事实顺序，补来源不重排；公开返回全部链接，范围只保存在事件。相同事实明确复用动作 ID，不凭文案哈希合并。

时间只按来源明确事实解析，不使用作者惯例或模型预测；缺年份和时区按共享 v2 规则补全，显式冲突转复核。有来源确认缺实际生效时间时使用确认来源发布时间。只有 confirm 允许 sources=[]，且须明确生效时间，标题摘要说明人工核实或推定；后续官方确认更新同一动作来源、标题摘要及实际时间，保持 ID。人工确认使用原有动作流程，无独立核实结果或未生效暂停能力。分钟任务保存到期预告的推定确认，读页面和 API 不写库；模型只读取有来源官方动作。新预告、计划修订、延期、取消可使旧无来源确认不再决定当前结果，动作和审计保留。公开 updates 完整包含无来源确认，不返回独立确认元数据；历史先生成确认再建立通知基线，不补通知。

业务只有事件、动作、帖子三张表，不维护帖子事件绑定。帖子保存原文 text、单层随帖引用 quoted_post、七语言标题摘要及原帖链接，不存全文翻译或原始响应；运行识别直接读取帖子。原文仅后台管理员可读，不进事件、动作、公开响应或业务审计，供应商响应仅留内部付费回执。事件只编辑类型、标题、摘要及范围，管理撤回与官方取消分开，无账户回执确认。事件页管理动作，帖子复核以选择器创建事件、添加动作或补来源，不手写 ID；事件、动作、来源、顺序变更分别表达，需预览的操作核验相关记录版本后一次提交。

帖子只保留 pending、processed、needs_attention、failed 四种识别进度及 review_reason，不维护 manual，也不以状态区分有无动作。worker 只识别 pending，写入核验原始版本；动作和来源管理、翻译不改变识别进度，明确完成帖子处理时设 processed 并清空原因。

## 入口

| 入口 | 用途 |
| --- | --- |
| `/claude-reset` | v2 当前结果与北京时间月历 |
| `/claude-reset/history/YYYY-MM-DD` | 北京时间按日事件及动作来源 |
| `/admin/claude-reset` | 事件列表与帖子列表两个 tab，默认事件列表；帖子包含已关联与未关联记录，只保留北京时间日期范围筛选，各自分页 |
| `/admin/claude-reset/events/:id` | 事件详情及动作、来源管理 |
| `/admin/claude-reset/posts/:id/review` | 帖子处理、动作及来源复核 |
| `/api/v2/overview` | 三平台来源、目录、统计和最近事件时间 |
| `/api/v2/claude-resets` | 事件列表及完整动作 `updates` |
| MCP `get_claude_resets`（带站点前缀） | 同一 v2 投影的文本和结构化数据 |

站点只通过 HTTP 读 v2，日历显式传 `timeZone=Asia/Shanghai`。Agent、MCP、飞书和 Webhook 共用动作投影及全部来源；监控 v1、旧站点数据和轮询接口删除，无兼容。详见[公共额度接口 v2](../../docs/reset-monitor-v2.md)。

全部读写限定 `monitor_id='claude'`，公开匿名，后台仅管理员。共享表转换先停旧写入、验证备份和指纹，转换前不启动新 worker，见[部署说明](../../docs/deploy.md#动作模型与-v2-切换)。开发与测试只使用独立测试库和本地假服务，不自动生产转换、真实调用、推送或部署。
