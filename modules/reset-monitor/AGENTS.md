# 共享重置监控引擎

此目录是 Codex、Claude 及后续 AI 重置监控共用的实现，不在站点清单中单独安装。

- 共享事件类型为 `direct_reset`、`reset_credit`、`bonus_credit`；各模块在公开定义的 `eventKinds` 声明启用类型，自动识别、后台编辑及人工复核都遵守该范围。语义见根目录 `CONTEXT.md`。
- 奖励额度保留金额或用量原话、资格条件、领取方式、领取截止与到期；时间只按独立来源中的明确时间和时区转换，未知保留原话。领取截止不能写成生效时间，官方可领取不能写成个人已到账；不生成模型预计时间或重置次数，统计、日历和通知按类型区分。
- 新建活动必须有主帖动作证据；同一活动的补充可通过已核验的官方回复或引用关系关联，但不能把父帖引文冒充主帖证据。明确动作与规则冲突须留复核原因，不得静默丢弃。
- 卡和奖励活动的后续提醒不能沿用直接重置的短候选窗口；回顾性确认缺少唯一目标时转复核，不以提醒日新增发放。明确额度周期从已核验的动作引文保留，不能借用同帖其他限额调整。
- 仅有 X Article 链接且正文未保存时标记资料不完整，不得标成已确定无关或创建事件；公开健康与后台复核须反映这一限制。

- `definition.ts`、`contracts.ts`：无后端依赖的配置和共享类型；`backend/` 与运行配置不得进入浏览器。
- `backend/`、`api/`、`web/`：共享采集、事件处理、人工复核、公开投影与页面。供应商格式仅在 `backend/providers/` 处理。
- `migrations/`：共享监控表的新迁移，一文件一语句；Codex 历史迁移留在原目录不改。
- `tests/`：通用行为、监控隔离、迁移与扩展测试，数据库必须以 `_test` 或 `_ci` 结尾；外部请求仅连接本地假服务。
- AI 专属提示词、套餐与时间策略放在各自模块，共享引擎不得写死作者、产品或发放惯例。
- 主作者使用非空 `authors` 列表，账号不区分大小写。逐账号完整采集相同窗口，所有采集、上下文和识别成功才推进监控检查点；保存和展示实际作者。
- 经使用者明确指定的有限采集范围可通过服务端 `collectionFilter` 限定查询与帖子筛选。范围外的已存待处理帖保留原文并记录筛选原因，不补采上下文、不调用模型；不得冒充模型识别或覆盖人工处理。默认不筛选，Codex、Claude 行为不变。
- 范围可拆为多个查询，逐作者依次完整分页各查询，游标独立、按帖子 ID 去重；所有查询成功后才推进统一检查点。
- 模块可提供默认产品、范围冲突及跨作者关联策略；要求明确跨作者依据的模块不能只靠时间相近关联不同作者的事件。产品默认值仅补缺失值，不覆盖已有事件或人工字段。原始模型结果必须保留。
- 专属非重置规则通过可选 `excludeProposition` 返回排除原因。引擎保留命题编号、原始模型结果及排除原因，排除命题不能参与事件、复核或关联；全部排除且无故障线索时归为无关，人工复核仍由管理员决定。
- 所有重置监控共用 `monitor` 模型能力及 `MONITOR_MODEL`，未指定时使用 `LLM_*` 默认模型；模块不提供独立模型选择配置。
- 供应商请求通过共享预算控制。TwitterAPI.io 免费套餐真实返回 HTTP 429，要求至少 5 秒间隔；适配器固定间隔 5.5 秒，进程内所有监控共用等待队列，不提供环境变量配置。失败释放队列但不重试请求。
- 所有数据库读写绑定服务端监控定义；主键与外键包含 `monitor_id`。调用者不能通过 HTTP 输入改变监控范围。
- 保留 Codex 的入口、运行名称、历史标识和行为。其他监控名称由监控 ID 生成。
- 初始化需显式有限时间范围；仅初始化保存分页断点到现有 `monitor_state`，按监控和提供商隔离，绑定相同起止时间、作者顺序、查询与筛选版本。页内帖子、回执完成和下一页断点一起提交；全部采集完成后保留断点直到上下文与识别成功，再原子写成功检查点并清理断点。失败即退出，由使用者以相同参数重跑续采，不自动重试；范围或配置变化先报错，不能误用断点。普通增量扫描与每日查漏不保存或使用分页断点。付费请求经过回执、预算和安全阀。
- 分页断点不绑定采集供应商账号或密钥；同供应商更换凭据后继续相同初始化，不重复请求已提交页。不复用其他供应商的游标，不自动重试失败或计费未知请求，不宣称未知请求未扣费。
- 初始化未提交页使用持久化请求标识，已经收到的有效响应在重跑时复用回执，不因业务写入失败再次购买；明确拒绝、未发送或无效响应失败即退出，下次显式续跑可在同标识下新增尝试，正在进行的请求不另行放行。普通扫描仍使用每轮独立回执。
- 初始化搜索、上下文和识别使用持久请求标识；同标识重跑只允许明确拒绝、未发送或无效响应的失败再次请求，任何未知计费尝试均阻止放行。停止状态及预算在节流等待结束、实际发送前再次检查，尚未发送的取消不能记录为计费未知。
- 初始化可分阶段执行：`--collect-only` 只采主帖并筛选，不补采上下文、不调用模型、不推送、不推进成功检查点；只有所有查询及后续处理完成才能显式完成初始化。扩大查询使用额外补采查询保留旧游标，禁止静默替换已开始的查询或宣称未补采范围已完整覆盖。
- 离线数据与临时工具放 `.data/local-preview/`，不提交凭据或生产快照。架构与新增监控步骤写在 README。
