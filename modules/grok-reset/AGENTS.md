# Grok 额度动态

本目录只保留 Grok 配置、识别与产品策略、时间策略和共享引擎的薄入口。

- 主信源来自 `site/reset-monitors.ts`，初始为 `@bot` 与 `@grok`，配置账号均可独立提供官方事件依据；其他作者仅作上下文。
- 沿用适用产品和套餐。账号默认产品在站点配置声明：初始 `@bot` 为 Grok Bot，`@grok` 为 Grok 普通额度；原文明示优先，套餐不推测。默认产品不得覆盖已有事件或人工字段。
- 启用 `direct_reset`、`reset_credit`、`bonus_credit`。普通限额调整、日常自动重置、API 赠金、政策解释和玩笑不生成事件。
- 产品及套餐冲突不能自动合并；跨账号关联需要同一事件依据，歧义留人工复核。奖励可领取不表示个人到账。
- 时间只按原文明示的时区或相对时长换算，缺时间保留原话，不预测。
- 共用 `MONITOR_MODEL`、供应商凭据、回执、预算和安全阀。通用实现位于 `../reset-monitor/`，不复制业务代码或新建表。
- 测试只连接本地假服务，样本注明模拟；不自动开启采集或推送。修复和测试不构成继续付费采集的授权。

- 统一执行共享引擎的非回复主帖增量流程；不采回复、自回复、转推，不补采父帖，不使用旧初始化、历史查漏或处理模式。主帖识别后关联事件并补齐 v2；历史事件及相关证据保留，无关旧采集数据按可预览、可恢复的清理计划删除。
