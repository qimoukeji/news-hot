# Codex 重置监控模块

本模块负责 Tibo（`@thsottiaux`）的 Codex 额度重置与重置卡监控；框架通过 `site/modules/` 安装，不直接导入本模块。通用实现位于 `../reset-monitor/`；此目录保留 Codex 的配置、提示词、时间策略、薄入口、行为回归测试及不可改写的历史迁移。

`eventKinds` 仅启用 `direct_reset` 与 `reset_credit`，保留现有行为；共享引擎的 `bonus_credit` 由其他已声明模块使用，不自动改变 Codex 的识别范围。

## 目录

- `module.ts`、`server.ts`、`web.tsx`：地址声明、后端接入、网页导航。
- `contracts.ts`、`config.ts`：共享类型与配置，前端不得导入后端配置。
- `backend/`：绑定 Codex 定义的薄入口，通用实现不放在这里。
- `web/`：绑定 Codex 展示配置的路由入口，通用页面在共享引擎；数据只从 HTTP 读取。
- `migrations/`：不可改写的历史迁移；共享表的新迁移在 `../reset-monitor/migrations/`。
- `tests/`：本地假服务和独立测试数据库；禁止真实模型、采集与推送请求。
- `scripts/`：模块命令行入口；初始化必须显式指定起止时间并遵守付费安全阀。
- 离线实帖评估的输入、逐条标注和报告存放在 `.data/local-preview/`，不提交凭据或生产数据库快照；只读导出，事件组装在独立测试数据库验证。

## 执行规则

预告、预计生效、实际确认和人工核验分别表达；经过预计时间不代表已确认完成。重置卡与直接重置不能混为一件事。
同一帖子对同一次发卡或重置的解释不能新增事件；明确的多轮重置保留各轮。后续明确事实补全事件，空字段不能擦除已有信息。多个可能的关联目标转人工复核，不按最近时间强行选择。原帖截止时间不因推算而延长。
进度与确认只补全未知对象，不覆盖已有适用范围；范围更正用明确的补充说明。相对时间继承被回复原帖的日期，记录时间来源；明确钟点保持单个钟点，不扩大为一小时。解释、惯例、条件政策和隐含惊喜不新增事件，按相关或无关处理；只有明确事件动作存在影响入库的关键冲突或缺失才转人工复核，同帖各命题独立判断。
正常扫描范围为上次整轮成功截止时间到本轮开始时间，每页成功立即保存。主帖、必要上下文和待处理识别全部成功才推进截止时间，业务复核不阻止成功。请求失败或结果未知标记失败并中止本轮；无恢复、重试次数、放行和跨轮分页续跑，下一轮正常扫描补齐。每日查漏最近 24 小时，不推进正常扫描截止时间。
首次初始化必须指定有限的起止时间；没有成功截止时间且未指定初始化范围时，在付费请求前中止。生产定时队列不重试失败任务，已有队列和排队任务也遵守此规则。回复和引用指向的历史事件优先提供给识别，不受近期事件窗口限制。
人工命题与事件使用明确关联，不能用相同摘录推断归属；多轮命题保留各轮关联，重新打开复核不能复制命题。已撤回事件的原有关联允许保留并编辑帖子，不能新增关联或因此恢复事件。自动归组保留有效的明确目标，每个明确轮次都必须入库或进入有原因的复核。
人工复核对所有帖子开放，查看依据、修改判断与关联、预览影响后一次事务提交，必须有理由和版本核验。保留模型原结果与人工审计；人工完成后 worker 不覆盖。关联调整同时重算受影响事件；失去唯一依据撤回，有其他有效确认则保留确认。官方确认与账户回执核对分别记录，已有确认或有效确认关联不能重复账户核对。后台事件和帖子列表默认每页 10 条并显示总数、页数；事件候选独立查询。
采集和模型调用遵守现有安全阀，付费请求全部使用回执与预算。切换提供商时不复用另一家提供商的分页游标。
事件列表提供“需回执核对”筛选，与确认按钮使用相同条件：未撤回、尚未确认、没有确认关联；筛选后的总数和分页使用同一条件。
后台“事件”和“帖子与识别”的分页统一放在列表下方，空列表也保留总数与页数。
模型请求参数优先使用所选模型配置，未配置的字段才使用识别流程默认值；显式总输出上限不再叠加思考额度。
提示词和历史实现只保留本模块使用的内容，不恢复模型榜或其他已移除功能。
验证执行根目录 `AGENTS.md` 中的命令，并检查监控页面、公开接口和后台操作。
